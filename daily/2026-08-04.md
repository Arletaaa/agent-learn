## 今日学习内容

### LangGraph 状态图编排

- 理解了 LangGraph 的图模型：State + Nodes + Edges → Compile → App
- 掌握了 Agent 循环的标准拓扑：agent → [conditional] → tools → agent
- 学习了 Checkpointer 持久化机制——用 thread_id 自动管理对话记忆
- 对比了手写 StateGraph 和 create_react_agent 的关系（底层是同一个东西）

### 核心认知

1. **图 > 链**：Agent 的本质是循环+条件分支，图才是正确的抽象
2. **State 是灵魂**：LangGraph 的 State 自动注入每个节点，不再手动传 messages
3. **Checkpointer 解决记忆问题**：之前项目一/三要手动拼接 messages，现在只需 thread_id
4. **手写和预制是同一枚硬币的两面**：create_react_agent 就是一个标准拓扑的快捷方式

## 心得体会

- LangGraph 本质上是一个"有状态的工作流引擎"，Agent 只是其中一种工作流类型
- 理解了图模型后，再看其他框架（LangChain Chain、CrewAI、AutoGen）就能看清它们各自的抽象层次
- LangGraph 的流式输出（stream）比 callback 模式更直观——每个节点一个事件
