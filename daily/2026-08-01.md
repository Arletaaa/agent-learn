## 今日学习内容

### Planning 策略对比

- 学习了五种主流 Planning 策略：ReAct（基准）、Plan-and-Execute、Reflexion、ReWOO、Tree of Thoughts
- 理解了每种策略的核心思想、执行流程和适用场景
- 通过项目四的对比实验，实际观察了三种策略在同一任务上的 Token 消耗差异

### 核心认知

1. **Planning 策略没有银弹**：每种策略有自己的 Trade-off，选择取决于任务特征（确定性 vs 探索性、Token 预算、质量要求）
2. **ReAct 是基石**：所有其他策略都可以视为在 ReAct 基础上的不同改进方向
3. **策略可组合**：如 Reflexion 可以用 ReAct 作为 Actor，Plan-and-Execute 可以加 Replan 步骤

## 实践记录

- 完成了 `compare_planning.py` 三种策略的实现
- 对比了 ReAct、Plan-and-Execute、Reflexion 的 Token 消耗和执行轨迹
- 实现了统一的 Token 统计机制

## 心得体会

- Planning 策略的选择不是技术问题，而是工程 Trade-off 问题——就像选择算法一样，要看数据规模（任务复杂度）、时间限制（Token/延迟预算）
- 理解"为什么 ReWOO 比 ReAct 省 Token"比理解"ReWOO 怎么写"更重要——因为背后是"独立步骤可并行"这个洞察
