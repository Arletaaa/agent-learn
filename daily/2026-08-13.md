## 今日学习内容

### AutoGen 对话式多 Agent

- 理解了 AutoGen 的"对话式协作"范式——Agent 自由发言而非固定流水线
- 掌握了双 Agent 对话模式：AssistantAgent（写代码）+ UserProxyAgent（执行代码）
- 学习了 GroupChat 群聊模式（Manager 决定发言顺序）
- 体验了 AutoGen 的招牌特性：代码执行闭环

### 核心认知

1. **三种编排范式对比**：LangGraph（图）vs CrewAI（流水线）vs AutoGen（对话）
2. **代码执行闭环是杀手锏**：写代码 → 执行 → 报错反馈 → 自动修正，无需人工介入
3. **对话式 = 控制与涌现的权衡**：AutoGen 放弃精确控制，换取自然协作
4. **框架互补而非互斥**：三个框架解决不同层次问题，可混用

## 实践记录

- 项目七：双 Agent 代码执行闭环（写斐波那契函数 → 自动执行 → 验证）
- GroupChat 多角色协作（程序员 + 评审）
- 使用 `human_input_mode="NEVER"` 实现全自动执行
- `use_docker: False` 实现本地代码执行

## 心得体会

- AutoGen 的"对话"比 CrewAI 的"流水线"更自然——像真的开会，谁有话谁发言
- 但自由度也有代价：对话可能跑偏，需要 `max_round`、终止关键词等约束
- 三框架对比后，对"编排层次"有了清晰认识：LangGraph 最底层，AutoGen 最上层
