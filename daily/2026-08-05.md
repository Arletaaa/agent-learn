## 今日学习内容

### CrewAI 多 Agent 协作

- 理解了 CrewAI 的三层模型：Agent（角色定义）→ Task（任务分配）→ Crew（团队调度）
- 掌握了 Sequential 流水线模式：研究员 → 分析师 → 写作者
- 通过 context 参数实现了 Task 间结果传递
- 对比了 CrewAI 与 LangGraph 的适用场景差异

### 核心认知

1. **角色扮演是高效的抽象**：Role + Goal + Backstory → 自动拼接 System Prompt，比手写 Prompt 更直观
2. **CrewAI 的 Agent 内部就是 ReAct**：框架层做的是"团队编排"，而非"推理机制创新"
3. **CrewAI 和 LangGraph 不是竞品**：前者适合"定义团队"的高层编排，后者适合"定义流程"的底层控制
4. **Sequential Process 的本质**：就是 Plan-and-Execute 策略在多 Agent 场景的实践

## 心得体会

- 用 CrewAI 构建 Agent 团队的体验和"分配工作任务给同事"很像——你定义角色和产出，框架处理执行细节
- 相比 LangGraph 的"图思维"，CrewAI 的"角色思维"更容易被非技术背景的人理解
- 但 Sequential 模式太刚性——如果研究员的信息不够，分析师没法要求研究员补充
