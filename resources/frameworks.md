# 框架与工具

> 收录主流的 AI Agent 开发框架和工具

## 核心框架

| 框架 | 语言 | 特点 | 官方链接 |
|------|------|------|----------|
| LangChain | Python/JS | 最成熟的 Agent 框架，生态丰富 | https://www.langchain.com |
| LangGraph | Python/JS | 基于状态图的 Agent 编排 | https://langchain-ai.github.io/langgraph/ |
| CrewAI | Python | 角色化 Multi-Agent，上手简单 | https://www.crewai.com |
| AutoGen | Python | 微软出品，对话式多 Agent | https://microsoft.github.io/autogen/ |
| OpenAI Agents SDK | Python | OpenAI 官方 Agent SDK | https://github.com/openai/openai-agents-python |
| Claude Code | TypeScript | Anthropic 终端内编程 Agent，MCP 原生支持 | https://docs.anthropic.com/en/docs/claude-code/overview |
| OpenCode | TypeScript | 开源 AI 编程 Agent，类 Claude Code | https://github.com/anomalyco/opencode |
