# AI Agents 学习笔记

基于大语言模型（LLM）的 AI Agent 开发学习项目，由 AI 协助管理和维护。

## 目录结构

```
agents-learning/
├── README.md            # 本文件 - 项目说明
├── AGENTS.md            # AI 管理指引（给 AI 看的规范）
├── roadmap.md           # 学习路线图（整体规划）
├── todo.md              # 待学习清单
├── learned.md           # 已学习内容索引
├── templates/           # 笔记模板
│   ├── daily-template.md
│   ├── concept-template.md
│   └── project-template.md
├── daily/               # 每日学习日志
├── concepts/            # 知识点/概念总结
│   └── index.md         # 概念索引
├── projects/            # 实践项目记录
└── resources/           # 学习资源收集
    ├── papers.md
    ├── tutorials.md
    ├── frameworks.md
    └── communities.md
```

## 使用方式

- 每日学习后，AI 会根据模板生成 `daily/YYYY-MM-DD.md` 日志
- 整理知识点时，AI 会创建 `concepts/` 下的概念文档并更新 `index.md`
- 学习路线图 `roadmap.md` 随进度逐步细化
- 资源收集到 `resources/` 对应文件中
- 所有内容由 AI 按照 `AGENTS.md` 规范管理
